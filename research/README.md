# Research: Similar apps and user needs

This folder collects the research we may use for the requirements for our GPS app that tracks Flock cameras.

## Existing products

### DeFlock (deflock.me)
-**What it does:** Web map of ALPR cams, crowdsourced and stored in OpenStreetMap.

-**Pros:** Community maintained camera dataset. Open data that we can reuse with the Overpass API.

-**Cons:** It's a map you browse, not a navigation app. No routing, no alerts while driving, and no way to see camera exposure when commuting.

-**What we can use from it:** We can use OpenStreetMap as our camera data source.

### Waze
-**What it does:** Navigation with alerts for police, speed cameras, and red-light cameras.

-**Pros:** Real time alerts while driving and has community reporting.

-**Cons:** Does not track Flock cameras.

-**What we can use from it:** Alert design and the one tap reporting.

## Google Maps
-**What it does:** Standard navigation. Shows speed cameras in some areas.

-**Cons:** No Flock camera awareness and can't route around specific points.

-**What we can use from it:** Familiar route planning interface users already expect.
